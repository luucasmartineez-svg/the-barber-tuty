# 💈 The Barber Tuty

## Descripción del proyecto

The Barber Tuty es una aplicación web desarrollada con Angular para administrar las actividades de una barbería.

El sistema permite gestionar clientes, servicios y turnos desde una interfaz sencilla y organizada.

## Funcionalidades principales

- Inicio de sesión con roles de administrador y barbero.
- Gestión de clientes.
- Administración de servicios, precios y duración.
- Registro, modificación y cancelación de turnos.
- Operaciones CRUD (crear, consultar, modificar y eliminar).
- Formularios con validaciones.
- Navegación entre las diferentes secciones de la aplicación.

## Tecnologías utilizadas

- **Angular:** desarrollo de la aplicación.
- **TypeScript:** programación de componentes y servicios.
- **HTML y CSS:** estructura y diseño.
- **Angular Material:** componentes de interfaz.
- **MockAPI:** almacenamiento y consulta de datos mediante peticiones HTTP.
- **Git y GitHub:** control de versiones del proyecto.

## Conceptos de Angular implementados

- Componentes y servicios.
- Ruteo con Angular Router.
- Guards para controlar el acceso según el usuario.
- Formularios reactivos y validaciones.
- Pipes para presentar información.
- Directivas.
- Carga perezosa (Lazy Loading) en la sección de turnos.
- Servicios HTTP y operaciones CRUD.
- Pruebas unitarias.
